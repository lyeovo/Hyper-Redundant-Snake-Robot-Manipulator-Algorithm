3统一价值函数

所有方法共享单一标量势（armValue/armGradient），避免「各方法各写一套代价」的腐败。

V(q) = w_pos · ‖p − X_t‖²                    % 末端位置误差
     + w_ang · wrap(θ − θ_t)²                % 末端角度误差
     + w_obs · Σ [ log(r_bar) − log(g_eff) ] % 障碍对数屏障（激活于 barrier_range 内）
     + w_var · Σ (q − μ)² / σ²               % 关节先验（默认关闭）

g_eff = max(d − d_safe, g_min)              % 侵入饱和排斥，防 log(负)/除零
数值防御：g_min 防除零、barrier_C 幅值截断、wrapAngle 角度连续化、动态权重调度（w_ang *= 0.5+1.5·(1−s)）打破位置-角度梯度互消。

4求解方法一览

覆盖「梯度局部精修 → 采样全局 → 图引导 → 学习加速」四种范式，auto 自动调度。

方法定位精度 / 语义说明
momentum局部精修（快路径）硬达标 1e-4 / 1e-3动量 + β 近目标衰减 + 回溯线搜索；卡住早停 error_code=7
rrt*采样层（主）粗达 0.02/0.1 + 精修渐近最优（choose-parent + rewire + 代价优化）
graph图引导层粗达 + 精修走廊图 + A* + 逐段 RRT*，窄通道/多障碍逃逸
prm采样层（辅）粗达 + 精修路线图 + 真 A* + 终点精修
sa逃逸兜底≈ 0.02Metropolis + 几何冷却，侵入样本硬拒绝
rl经验加速—OpenAI-ES 策略梯度 + residual 集成
cvae学习层≤ 0.01多模态轨迹生成 + 潜空间优化 + 终点精修
auto默认推荐各方法见下方调度链

auto 自动调度链

momentum → RRT* (预算1) → RRT* (预算2 ×2) → graph → PRM → SA
  快路径（毫秒级）                        逐层升级（失败才触发下一层）      全失败取末端误差最小者
设计动机：无障碍/易达 → 梯度快路径；多障碍/窄通道 → 采样类概率完备；目标深陷障碍 → 图引导。局部最优由 detectLocalMin（‖∇V‖<tol 且末端未达）判定。

5任务生命周期与状态机

runTaskLoop 轮询 outbox → taskExecute 逐段求解 → 回写 inbox 状态 → 导出 motorCmd。

RECEIVED → ACCEPTED → PLANNING → EXECUTING → COMPLETED
                ↓                        ↓
             REJECTED               FAILED / CANCELED / ESTOP_TRIGGERED

任务类型（command_type）与夹爪状态机

  • move_near_target — 靠近目标
  • pick_target — 夹取
  • pick_and_place — 夹取-放置
  • dock_to_interface — 对接
  • home — 归位

夹爪状态机 gripper_seq（与 q_seq 逐行对齐）：

  • 0 = 保持 · 1 = 张开 · 2 = 闭合
  • 动作在段末快照触发（如 GRASPING 段末闭合）
