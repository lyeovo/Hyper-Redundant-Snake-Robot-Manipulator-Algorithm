1五种范式总览

所有方法都解同一个问题：给机械臂一组关节角 q，让末端位置/角度到目标 [X_t, θ_t]，且不碰障碍。区别只在“怎么在这个高维关节空间里搜索”。

范式方法走优点代价

采样全局rrt/rrtstar/prm/sa在关节空间随机撒点无局部最优概念，概率完备慢（秒级）；结果是“粗达”

背后共同的唯一事实来源是价值函数 V(q) 与其解析梯度 ∇V(q)（§2）。采样类方法也用 V 作为“目标达成度”来判定成功，但不靠它寻路（避免被势阱吸引）。

2共享数学基础

下面是所有方法的“地基”。先把记号统一：q∈R^N 关节角、p(q) 末端位置、θ(q) 末端朝向、X_t/θ_t 目标、d_k(q) 到第 k 个障碍的距离。

2.1 统一价值函数 V(q)

V(q) = w_pos·‖p(q) − X_t‖²                          % 末端位置误差
     + w_ang·wrap(θ(q) − θ_t)²                      % 末端角度误差
     + w_obs·Σ_k [ log(r_bar) − log(g_eff,k) ]       % 障碍对数屏障（仅 g_eff,k < r_bar）
            + w_obs·barrier_C·(d_safe − d_k)          % 侵入线性惩罚（仅 d_k < d_safe）
     + w_var·Σ_j (q_j − μ_j)² / σ_j²                % 关节先验（默认 w_var=0）
     + w_acc·‖v − v_prev‖²                          % 加速度平滑（仅 w_acc>0，动量法置 0）

其中 g_eff,k = max(d_k − d_safe, g_min)（防除零/防 log 负）、d_safe = rho0 + safe_margin、r_bar = barrier_range。

为什么这样写①位置/角度两项是最小二乘，梯度是闭环的；②屏障用 −log(g_eff)：障碍越近 g_eff→0 时 V→+∞，把臂“推开”；③barrier_range 让障碍远时势为 0（避免远处 −log 变负势干扰位置收敛）；④侵入后叠加线性项，压过位置项（否则 RL/SA 这类非梯度法会停在侵入态）。

2.2 解析梯度 ∇V(q)

∇V = −2·w_pos·e_pos·J − 2·w_ang·e_ang·J_ang                  % e_pos=X_t−p, e_ang=wrap(θ_t−θ)
   − w_obs·Σ_k [ clip(1/g_eff,k, 0, barrier_C) · ∇d_k ]          % 屏障梯度（幅值截断）
   + 2·w_var·(q−μ) ⊘ σ²
   + 2·w_acc·(v−v_prev)

J = ∂p/∂q（2×N）是末端位置雅可比、J_ang = ∂θ/∂q（1×N）是角度雅可比。

关键点：屏障幅值用 g_eff 截断（clip(1/g_eff, 0, barrier_C)），但方向始终用真实 ∇d（推离方向）——这就是“侵入后仍保持最大恒排斥（D5）”。梯度解析 + 机器精度校验（test_gradcheck 中心差分 < 1e-5）。

2.3 运动学正解与雅可比

正解（planarFK_L）：θ_sum ← θ_sum + q_i
  M_i  = P_{i−1} + L_i·[cos θ_sum, sin θ_sum]        % 第 i 段段端
  P'_i = M_i + rod_off_i·[−sin θ_sum, cos θ_sum]     % 垂直偏移点

几何雅可比（planarJac_L）：J(1,i) = −(y_end − y_i)；J(2,i) = (x_end − x_i)
  （旋转中心 = 段端节点；rod_off=0 时精确，否则忽略二阶耦合）

末端朝向角：θ_end = atan2( M_N − P'_{N−1} )           % 最后一段方向

注意这里 θ_end 取“末端段指向方向”，而非旧版反向——否则全零构型（臂沿 +X）会得到 θ=π 而非 0。

2.4 障碍几何（带符号距离 + 屏障）

点-圆：g = ‖p − c‖ − r                    % 侵入为负
段-圆：最近点 = 圆心在段上的投影（g = ‖投影−c‖ − r）
段-段：双参数 (ta,tb) 最近点；退化（点/平行）有分支防除零
点-矩形：g = max(|lx|−w/2, |ly|−h/2)（旋转坐标下）

模式 'seg'：逐杆段检测（默认，最安全）；'point'：仅电机节点（快速，可能漏检穿段）

距离的带符号约定让“屏障”能区分“还在安全区外的接近”与“已经侵入”两种状态。

2.5 回溯线搜索 + 局部最优检测

线搜索（momentum 内）：q_try = q + v；若 V(q_try) > V(q) + 1e-12 ⇒ v ← 0.5·v（重试 ≤6）

局部最优（detectLocalMin）：‖∇V‖ < localmin_tol_grad（1e-3）且 dist_end > tol_pos ⇒ 困于势阱

线搜索保证 V 单调下降、防震荡/伪平衡；局部最优判定是 auto 决定“是否升级到采样层”的依据。

momentum · 梯度局部精修（点击折叠/展开）

3momentum：梯度局部精修快路径

method_momentum info = method_momentum(model, q0, target, opts) 梯度局部精修

核心直觉：把 V(q) 看作一片“山谷”，末端的误差在山谷底最小。梯度 −∇V 指向“更快下降”的方向，于是沿反梯度一步步走。动量就是“惯性”：如果这几步一直朝一个方向，就冲得更快；方向反复横跳时，惯性被抵消。

数学逻辑

v_{k+1} = β_k·v_k + (1 − β_k)·(−∇V(q_k))              % 动量累积
β_k = β·erf( dist_end / (√2 · 0.05) )                 % 近目标衰减：dist→0 时 β→0，消末端震荡
若 min g < rho_critical：v ← v / max(1, rho_critical / max(min g, g_min))   % 近障碍降速
v ← v · min(1, dq_max / max|v|)                        % 步长上限
q_{k+1} = clip(q_k + v_k, q_min, q_max)                 % 限位 + 回溯线搜索

两阶段权重调度（打破位置-角度互消）

dist_end > 0.08：w_ang ← 0.2·w_ang；w_pos ← 1.0·w_pos        % 远：先让臂“到位”（位置主导）
dist_end ≤ 0.08：s2 = min(1, dist_end/0.08)                    % 近：用冗余自由度“调姿”
               w_ang ← w_ang·(0.2 + 3.8·(1 − s2))；w_pos ← w_pos·(0.3 + 0.7·s2)

运行步骤

  • 从 q0 出发，逐步算 armGradient → 更新动量 → 限幅 → 回溯线搜索。
  • 收敛判据：dist<tol_pos(1e-4) 且 |e_ang|<tol_ang(1e-3)（硬达标）；strict=false 时用“逐项贡献 <0.001 连续 5 步”动态收敛。
  • 无进展早停：每 30 步记一个窗口误差，近 3 窗口 vs 前 3 窗口无实质改善（>1e-4）⇒ 卡住，error_code=7。

优点毫秒级；无障碍/简单场景直接收敛到高精度（1e-4/1e-3）；也常被采样法用作“多起点小精修”。
局限只到局部最优——被障碍势阱困住就出不来；对障碍屏障的非凸性敏感。
在 auto 中它永远先跑：快路径一成功就立刻返回，不做任何多余开销。

4sa：模拟退火逃逸兜底

method_sa info = method_sa(model, q0, target, opts) 采样全局

核心直觉：高温时像“乱撞”一样允许接受较差解，从而翻过小山包（逃离局部最优）；随着温度降低，越来越只接受更好的解，最终落入一个好山谷。

数学逻辑（Metropolis + 几何冷却）

T_0 = max(V(q0), 1e-3)                    % 初始温度自适应
每步：σ_k = σ_0·√(T_k / T_0)                 % 扰动幅度随温度收缩
  q_p = q + σ_k·randn(N)；q_p = clip(...)     % 高斯扰动
  若 min g(q_p) < rho0 ⇒ 直接拒绝（冷却后 continue）     % 侵入硬拒绝
  ΔV = V(q_p) − V(q)
  accept if ΔV < 0 OR rand < exp(−ΔV / T_k)     % Metropolis 准则
T_{k+1} = α·T_k                              % 几何冷却（α=0.995）

运行步骤

  • 迭代直到 max_iter 或收敛；始终记录 q_best（历史最优）。
  • 收敛检查基于 q_best 的末端误差 < tol_pos/tol_ang。
  • 结束若未收敛，用 refineRandomGreedy（layers=4, steps=250）做无梯度终点精修兜底。
安全约束是硬性的：扰动样本一旦侵入障碍（min g < rho0）就直接拒绝，不进入 Metropolis——防止高温把臂“推”进屏障。这是 SA 与“软屏障势”方法的本质区别。
优点翻越局部最优；对非光滑/有障碍势阱的场景有效；实现简单。
局限慢（~2000 迭代）；只能达“接近”（≈0.02 再精修）；冷却参数敏感。
在 auto 中是最后兜底（max_iter 被降到 600 以实时约束）。

5rrt：概率完备采样采样层（对比）

method_rrt info = method_rrt(model, q0, target, opts) 采样全局

核心直觉：在关节空间“乱撒点”，从起点长出一棵树，每次把新点连到离它最近的树节点上，只要这条边不碰障碍。样本越多，树越能绕过障碍、逼近目标。

数学逻辑（RRT）

采样 q_rand：30% 从目标种子附近扰动（σ_seed=0.05+0.2·(1−min(1,best_err))），否则均匀
最近邻：q_near = argmin_i ‖q_rand − q_i‖                    % 加权欧氏
steer：q_new = q_near + min(1, max_step/‖Δ‖)·Δ；clip 到限位
边检查：edgeFree = 沿边插值 n_chk=max(3,ceil(‖Δ‖/0.4)) 点逐点查碰撞（防穿段漏检）

运行步骤

  • 多起点动量种子（6 个随机初值跑 30 步动量，取末端误差最小者作目标种子）绕开势阱。
  • 目标区域判定参数化：位置 goal_eps（0.02）+ 角度 goal_ang（0.1）。
  • 粗达（末端 < 0.4）即触发 refineRandomGreedy 精修，达标则成功；否则继续扩展。
  • 失败返回最近可达节点（warm start，error_code=3）。
为什么“无梯度局部最优”：障碍只是采样拒绝条件，不构造势场。所以 RRT 不会被 V 的势阱“吸住”——它天然能绕过障碍。
优点概率完备（样本→∞ 找到概率→1）；无梯度局部最优；实现简单。
局限路径未必最优（会绕路）；慢；只能“粗达 + 精修”。

6rrtstar：渐近最优采样层（主）

method_rrtstar info = method_rrtstar(model, q0, target, opts) 采样全局

核心直觉：相比 RRT，它多做了两件事：选父（新节点在半径内找“根代价最小”的节点接上去，而不是最近邻）和重连（半径内邻居若“经过新节点”更短就改接）。这两步让树的路径代价单调不增，从而渐近最优。

数学逻辑（RRT*，Karaman & Frazzoli 2011）

代价 c(q) = 根到节点的加权 C-space 路径长度                % 渐近最优的目标
rewire 半径 r = min( γ·(log m / m)^(1/N) , max_step·3 )     % 随节点数收缩

② choose-parent：q_new 在半径 r 内选 根代价 + 边代价 最小且边无碰撞的父（非最近邻）
③ rewire：半径内邻居 j，若 c(new)+dist(new,j) < c(j) 且边无碰撞 ⇒ 改接 parent(j)=new

采样引导：8% 从种子扰动（高比例偏置会破坏渐近最优收敛），其余均匀

运行步骤

  • q0 邻域先铺 64 个自由种子（贴障碍起点的可扩展锥极窄）。
  • 每次采样 → 最近邻扩展 → choose-parent → 加入树 → rewire；粗达候选（预算内最优，最多 8 个）入候选池。
  • 精确命中（<goal_eps 且 <goal_ang）提前返回；否则循环结束后对候选逐个 refineRandomGreedy 精修，并校验“树末节点→精修点”无碰撞，取总代价最小达标者。

2D 适配层：这个方法的“核心”是纯关节空间、维度无关的；只有 isFree/fkEnd/goalDist/edgeFree 四个嵌套函数是 2D 特有的。3D 演进只需替换这四个而不动核心。
“渐近最优”与实现有一处保留：代码保留了 8% 目标种子引导采样，目标偏置会拖慢渐近最优收敛。因此更准确的说法是“带引导的近似最优”，并靠 mean_gap 实测路径质量。若要严格宣称渐近最优，需去掉该偏置（会明显变慢）。
优点路径质量优于 RRT；auto 链默认主方法（“带引导的近似最优”）。
局限比 RRT 慢；仍是采样类，只能“粗达 + 精修”；预算不足会失败（靠 auto 升档 ×2 重试）。

7prm：路线图采样层（辅）

method_prm info = method_prm(model, q0, target, opts) 采样全局

核心直觉：先一次性建好一张“路网”，再用 A* 在上面找路。与 RRT 的区别：RRT 一边长树一边找，PRM 先建完整个图再搜——适合“多起点/多目标”或反复查询。

数学逻辑（PRM，固定连接半径路线图）

节点：起点 + 目标种子 + 无碰随机点（30% 种子引导，保证目标区域稠密）
连接：节点对距离 ≤ rad 且 edgeFree（边插值检查）则连边
A*：起点=1，目标种子=2，启发 h = 到种子的欧元距离；重建路径
终点：无梯度 refineRandomGreedy（layers=4, steps=200）
命名说明：这里是固定连接半径（rad，默认 cfg.prm_rad=1.2），不是 PRM* 的收缩半径公式；节点数默认取 cfg.prm_n_nodes。因此宜称“PRM（固定半径路线图）”，避免与 PRM* 混淆。
失败（A* 无路径）返回最近可达节点（warm start，error_code=3）；精修未达标返回路径终点（error_code=2）。
优点静态路网可复用；与 RRT* 采样互补；A* 给出较优路径。
局限建图开销 O(n²)；高维关节空间路线图稀疏；同样只能“粗达 + 精修”。

8graph：图引导分层窄通道/多障碍逃逸

method_graph info = method_graph(model, q0, target, opts) 图引导

核心直觉：RRT/PRM 在“多障碍、窄通道”里像无头苍蝇。图引导先在工作空间里找出“障碍之间的缝隙/绕行点”，建一张走廊图，再用 A* 给出一条“该往哪走”的序列，最后逐段用 RRT* 在关节空间去实现。

数学逻辑（走廊图 + A* + 逐段 RRT*）

膨胀：障碍外扩 (rho0 + margin)（圆半径 +d；矩形宽高 +2d）
节点：圆-圆/圆-矩/矩-矩 缝隙中点 + 每障碍 4 方向绕行点 + 起终点 + 随机自由点
边：pipelineFree —— 末端沿直线走，半径 rho0 的圆不碰膨胀障碍（管道检查）
A*：起点→终点走廊序列；坏边软惩罚 ×5（仍可作最后手段）
逐段：走廊段 RRT* 末端到节点（角度保持上一段终态）；最后一段到 target（含角度，精修达标）
回溯：段规划失败 ⇒ 标记坏边 ×5 重搜换路；同段反复失败 >1e4 则封死（inf）

gap_max1.0缝隙宽度阈值（超过可直连）
max_iters8回溯迭代上限
total_budget12000全任务累计样本预算
维度无关：走廊节点只含末端位置 (x,y)（走廊语义）。3D 演进只改 fkEnd 输出维度与障碍几何（球/盒），A* 与回溯逻辑不变。
优点窄通道/多障碍逃逸成功率高于单 RRT*；给出“该往哪走”的结构化引导。
局限建图开销；走廊只约束末端位置（不约束姿态），最后一段才处理角度。
在 auto 中位于 RRT* 之后、PRM 之前——它是“采样层打不过才上”的进阶。

9rl：OpenAI-ES 强化学习经验加速

method_rl info = method_rl(model, q0, target, opts) 学习加速

核心直觉：不显式建模，而是学一个“给点状态就输出关节增量”的小策略。用进化策略（ES）在任务里扰动策略参数、看哪次表现好，就往好方向更新——这是一种黑箱参数搜索，不依赖梯度可导。

数学逻辑（OpenAI-ES 参数扰动 + residual 集成）

状态特征 s = [ e_pos归范(2), e_ang/π, min_g归范, q归范 ] ∈ R^D，D = 2+1+1+N
策略 π_θ(s) = θ·s'  ∈ R^N           % 线性策略
动作 dq = −0.05·∇V' + λ·π_θ(s)      % residual 集成：动量梯度 + 学习项

ES 更新：扰动 ε_p ~ N(0, σ²)；奖励 R_p = −(dist_end + 0.1·ang)
  R 归一化；grad_θ = (ε' · R) / (n_pop · σ)；θ ← θ + 0.5·grad_θ

关键参数

参数值作用
n_pop / n_gen16 / 20种群数 / 进化代数
sigma_es0.2扰动标准差
lambda0.3residual 权重
max_rollout60rollout 步数
为什么 θ=0 起点不劣于纯梯度：当 θ=0 时 π_θ=0，动作退化为纯动量梯度。所以 residual 设计的收益是“只会更好，不会更差”。
优点可学到规避策略；不依赖梯度可导；θ 可导出复用（stats.theta）。
局限任务内训练开销；线性策略表达受限；只在目标附近有效。

10cvae：学习层（CVAE 条件变分自编码器）毫秒直出

cvaePolicyFromFile / cvaePolicyDeploy out = cvaePolicyDeploy(mat_file, model, q0, target) 学习加速

核心直觉：把“离线全局最优规划（RRT*）”蒸馏成一次前向网络就能出轨迹。网络条件在“当前障碍布局 + 起点 + 目标”上，输出一段关节增量（而不是绝对角），从而天然锚定起点、保证连接。

数学逻辑（增量表示 + 潜空间优化推理）

增量表示：traj = q0 + cumsum(Δ, 1)，Δ 为网络输出（按 y_std·y + y_mean 反归一）
编码 x = [栅格化障碍, (q0−q_mean)/q_std, (target−t_mean)/t_std]     % 行主序 flatten
解码：3 层 MLP（ReLU）→ Δ；终态误差 err = ‖p−X_t‖ + 0.1·|wrap(θ−θ_t)|

潜空间优化：对 n_cand 个 z~N(0,I)，做 z ← z − lr·g，g 用中心差分 ∇_z err
  （解决 KL 塌缩下“训练后验 vs 部署先验”不匹配；CPU 下 ~1s/候选）

部署闭环（cvaePolicyDeploy）

  • CVAE 潜空间优化生成粗轨迹（毫秒~数百 ms）。
  • 逐帧 obsDistAll 碰撞检查；穿障或质量差（err>0.08）⇒ 回退 method_auto（可靠兜底）。
  • 终点无梯度 refineRandomGreedy（layers=3, steps=120）精修 ≤0.008。
为什么用增量而不是绝对角：轨迹 = q0 + cumsum(Δ)，起点被锚定在 q0，避免网络“从别处开始”。
优点毫秒~数百 ms 直出；可绕过势阱；多模态（多候选 z）处理不同绕行。
局限需离线训练与示范数据；泛化受限；可靠性靠安全层回退保证。

11auto：调度链 + 局部最优检测默认推荐

method_auto info = method_auto(model, q0, target, opts) 调度

核心直觉：没有单一方法通吃所有场景。auto 按“先快后稳”的顺序调用各方法：快路径（梯度毫秒级）→ 采样层（概率完备）→ 图引导（窄通道）→ 兜底（SA），上一层失败才触发下一层，全部失败则取末端误差最小者。

调度链与细分预算

0) momentum（快路径，精度 tol_pos/tol_ang）
1) RRT*（adaptiveBudget 自适应 + 失败升档 ×2 重试）
2) graph（max_samples=500, total_budget=2500）
3) PRM（n_nodes=100, max_samples=100）
4) SA（max_iter=600）
   全失败 ⇒ 取这几个候选里 dist_end 最小者；method_used='auto(全部失败)'

adaptiveBudget（采样预算启发式）

无障碍 且 dist<2   ⇒ 1500   % 简单省时（1500 成功率已饱和）
障碍 ≤ 2          ⇒ 3000   % 中等
障碍 > 2          ⇒ 6000   % 复杂自动加大
最终 min(b, rrt_max_samples)        % 受用户上限约束

局部最优检测（决定是否升级）

detectLocalMin：‖∇V‖ < localmin_tol_grad(1e-3) 且 dist_end > tol_pos ⇒ 势阱 ⇒ 升级到采样层
分层依据：①梯度层解决精度（快且准）；②采样层解决障碍连通性（概率完备）；③图引导解决窄通道/多障碍（成功率 > RRT*）；④SA 兜底漏网局部坑。预算启发式基于一个关键洞察：预算只对“样本不足型”失败有效，对“精修卡死型”无效。
优点快慢组合、鲁棒；简单场景毫秒返回，复杂场景也能兜住。
局限最坏情况要跑完整条链（较慢）；分段预算保守（实时约束）。

12multilayer：工作空间连通（LGM）臂无关连通层 + 逐段求解

method_multilayer info = method_multilayer(model, q0, target, opts) 工作空间连通

核心直觉：graph 的走廊图还是和臂绑在一起（可行性由 C-space 求解器逐段决定），而 multilayer 把“工作空间能不能连通”这一层独立出来做成 LGM（layering guidance model）：骨架化自由空间的“通道中线”成一张连通图，节点 = 走廊中心，边 = 连通性。图上搜出一条或多条候选路径，再交给下游 C-space 求解器一段一段实现。

数学逻辑（LGM 连通图 + 候选路径 + 逐段求解）

LGM 建图：bwskel（骨架线）→ 交点/端点/走廊中点(0.20R) → 节点；bwlabel 分支 → 边
          （也可 skeleton=false 走 PRM 型随机图）
候选集：graphPaths 枚举 DFS 简单路径（上限 4000）→ 按节点距离代价排序 → 取 k-最短路
逐段：目标 θ = 当前末端角（角度放开）；快速 momentum → 稳健 rrt 回退
      段成功判据 = 不碰障(safety_ok) + 在空间内 + 位置宽松(<waypoint_eps=0.4)
末尾：refineRandomGreedy 精确微调，dist_end<0.03 判成功（角度仅报告）

关键参数

参数值作用
use_multilayertrue开关；false → 快速单段兜底 fallbackSolve
k_paths2候选路径数（k-最短路）
max_segments9路径段数上限
seg_method_fast / _robmomentum / rrt段快速 / 稳健回退
waypoint_eps0.4中间路点位置宽松容差 m
GRID64连通图分辨率
candidate_idx0>0：只求解候选集第 idx 条
臂无关设计（可跨臂复用）：LGM 图里没有任何机械臂参数（不存臂长/关节/可达半径），只描述“走廊能走通”。拿一张 LGM 图，可以给任意臂、任意 N 复用；可行性判断被下放到逐段 C-space 求解器（momentum/rrt），实现“图只管连通，臂只管可行”的解耦。
优点臂无关、可复用；候选集（info.candidates）为复杂运动情形“多留几条路供选择”；输入 0.4m 宽放 + 末尾精修，中间松、终点准。
局限建图要看场景（骨架需 Image Processing Toolbox）；连通图不含可行性，需下游求解器兜底（可能整条候选失败 → fallback）。

13收敛性与最优性讨论

不同策略的“保证”级别不同——这是选型的关键。

策略保证级别能到达前提/代价
momentum局部收敛最近的局部最优需 V 可微、无障碍势阱
rrt概率完备只要存在路径，样本→∞ 找到概率→1足够样本预算
rrtstar概率完备 + 渐近最优路径代价 → 最优下界choose-parent + rewire + 半径收缩
prm概率完备（图连通）路网上的可行路径节点足够多、连接半径够大
graph启发式（走廊可行）走廊序列 + 逐段可达走廊连通、逐段 RRT* 成功
multilayer启发式（走廊连通）候选最短路段序列 + 逐段可达LGM 连通、逐段 C-space 求解成功
sa概率渐近收敛全局最优（温度趋于 0 时）冷却足够慢（现实中折中）
rl—（经验）目标附近策略直出训练过类似场景
cvae—（经验 + 安全层）直出粗轨迹 + 精修需要示范数据，回退保底
为什么采样类都“先粗达再精修”：RRT*/PRM 保证“能连过去”，但不保证末端的精确角度。所以它们都在达标区域内用 refineRandomGreedy（无梯度随机贪心）做终点精修——绕开梯度势阱，把位置/角度磨到目标容差。

14横向对比与选择指南

方法范式速度精度最优性反向依赖
momentum梯度毫秒高（1e-4/1e-3）局部需可微 + 无障碍势阱
sa采样秒≈0.02 + 精修概率渐近冷启动
rrt采样秒粗达 + 精修概率完备采样预算
rrtstar采样较慢粗达 + 精修渐近最优预算、rewire
prm采样较慢粗达 + 精修概率完备建图
graph图引导中粗达 + 精修启发式走廊连通
multilayer工作空间连通中不碰障+在空间内（宽松）→ 精修<0.03启发式LGM 连通、逐段可行
rl学习毫秒（θ 已知）目标附近经验离线训练
cvae学习毫秒~数百 ms≤0.01经验示范 + 安全层
auto调度随场景取各层对应实际用到的层全链兜底

怎么选一句话决策

  • 无障碍 / 目标易达 → 直接 momentum（最快）。
  • 有障碍 / 不确定 → 用 auto（自动分层，最省心）。
  • 看重路径最优 → rrtstar（渐近最优）。
  • 窄通道 / 多个障碍 → graph（图引导逃逸）。
  • 要看“有哪几条路可走” / 想给复杂运动留候选 → multilayer（LGM 连通 + 候选集）。
  • 要毫秒级在线 → cvae（离线训练，在线直出）。
  • 只想看效果 → GUI 里的方法下拉，逐个试。
一次记住的要点：梯度法负责“快与准”，采样法负责“能连过去”，图引导负责“知道往哪绕”，学习法则把前者的经验压缩成一次前向。auto 把它们排成一条“越来越稳、也越来越慢”的备用链。
