3统一价值函数与默认参数

所有方法共享单一标量势（armValue/armGradient），避免「各方法各写一套代价」的腐败；参数唯一事实来源是 modelDefaults.m。

V(q) = w_pos · ‖p − X_t‖²                    % 末端位置误差
     + w_ang · wrap(θ − θ_t)²                % 末端角度误差
     + w_obs · Σ [ log(r_bar) − log(g_eff) ] % 障碍对数屏障（激活于 barrier_range 内）
     + w_var · Σ (q − μ)² / σ²               % 关节先验（默认关闭）
     + w_acc · ‖v − v_prev‖²                  % 加速度平滑（动量法关闭）

g_eff = max(d − d_safe, g_min)              % 侵入饱和排斥，防 log(负)/除零
grad  ∇V = −2·w_pos·e_pos·J − 2·w_ang·e_ang·J_ang
        − w_obs·Σ [ clip(1/g_eff, 0, barrier_C) · ∇d_k ]
        + 2·w_var·(q−μ)⊘σ² + 2·w_acc·(v−v_prev)
数值防御：g_min 防除零、barrier_C 幅值截断、wrapAngle 角度连续化、动态权重调度（w_ang *= 0.2+3.8·(1−s)）打破位置-角度梯度互消；动量法把 w_acc 显式置零（用动量本身平滑）。

4求解方法一览与 auto 调度链

覆盖「梯度局部精修 → 采样全局 → 图引导 → 工作空间连通（LGM）→ 学习加速」五种范式，auto 自动调度。全方法共享统一 info 契约与 armValue 价值。

方法定位精度 / 语义说明
momentum局部精修（快路径）硬达标 1e-4 / 1e-3动量 + β 近目标衰减 + 回溯线搜索；卡住早停 error_code=7
rrt采样层（对比）粗达 0.02/0.1 + 精修保留作基线，无渐近最优保障
rrt*采样层（主）粗达 0.02/0.1 + 精修渐近最优（choose-parent + rewire + 代价优化）；auto 链默认
graph图引导层粗达 + 精修走廊图 + A* + 逐段 RRT*，窄通道/多障碍逃逸
prm采样层（辅）粗达 + 精修路线图 + 真 A* + 终点无梯度精修
sa逃逸兜底≈ 0.02Metropolis + 几何冷却，侵入样本硬拒绝
rl经验加速—OpenAI-ES 策略梯度 + residual 集成（θ=0 不劣于纯梯度）

auto默认推荐各方法见下方调度链

auto 自动调度链

momentum → RRT* (预算1) → RRT* (预算2 ×2) → graph → PRM → SA
  快路径（毫秒级）                        逐层升级（失败才触发下一层）      全失败取末端误差最小者
设计动机：无障碍/易达 → 梯度快路径；多障碍/窄通道 → 采样类概率完备；目标深陷障碍 → 图引导。局部最优由 detectLocalMin（‖∇V‖<tol 且末端未达）判定。auto 各层的细分预算覆盖：graph max_samples=500、PRM n_nodes=100、SA max_iter=600（实时约束下小图小预算）。

5任务生命周期与状态机

runTaskLoop 轮询 outbox → taskExecute 逐段求解 → 回写 inbox 状态 → 导出 motorCmd。

RECEIVED → ACCEPTED → PLANNING → EXECUTING → COMPLETED
                ↓                        ↓
             REJECTED               FAILED / CANCELED / ESTOP_TRIGGERED

任务类型（command_type）与夹爪状态机

  • move_to (x,y) — 末端移动到 (x,y)
  • move_along (θ,d) — 末端沿 θ 方向移动 d 米
  • move_for_pick — 依实时相对位置向物体移动
  • move_for_place — 依硬编码向放置位置移动
  • rotate (α) — 末端位置不动，旋转 α 角
  • rotate_arm (α,n) — 第 n 关节旋转 α 角
  • facing_arm (θ,n) — 第 n 关节面向 θ 方向
  • pick / place — 夹爪抓取 / 放置动作链
  • withdraw / reset — 退回上一状态 / 恢复初始位置

夹爪状态机 gripper_seq（与 q_seq 逐行对齐）：

  • 0 = 保持 · 1 = 张开 · 2 = 闭合
  • 动作在段末快照触发（如 GRASPING 段末闭合）
  • 参数（θ,d,α,n）从 cmd.motion_params 读取（不改 TaskCommand 结构）

每个 command_type 由 taskToSegments 展开为段序列；段按 kind 区分：ee（末端 [x,y,θ]）、ee_relative（当前末端沿 θ 移 d）、ee_rotate（原位转 α）、joint_delta（第 n 关节转 α）、joint_abs（第 n 关节连杆朝 θ）。taskExecute 用当前臂态解析相对/关节段（resolveSegTarget / execJointSeg）。

7.2 L1 价值层统一标量势与解析梯度

armValue V = armValue(model, q, v, v_prev) L1
统一标量势 V(q)，全部迭代方法共享的单一事实来源。公式见 §3。调用 planarFK_L + getEndEffectorAngle_L + obsDistGradAll。
参数含义
model模型对象（读 cfg.* 权重/目标/屏障）
q1×N 关节角
v / v_prev当前/上一速度（仅 w_acc>0 时参与；动量法传空）
返回标量 V。
屏障项在 g_eff < barrier_range 时激活；g_all(k) < d_safe（侵入）时额外叠加 barrier_C·(d_safe−g) 线性惩罚，以压过位置项（对 RL/SA 等非梯度方法尤重要）。
armGradient grad = armGradient(model, q, v, v_prev) L1
V(q) 的解析梯度 ∇V(q)，1×N。梯度方向始终用真实 ∇d（推出方向），屏障幅值用 g_eff 截断——侵入后仍保持最大恒排斥（D5）。
参数含义
model模型对象
q1×N 关节角
v / v_prev可选，加速度项贡献 2·w_acc·(v−v_prev)
返回 grad [1×N]。梯度校验：modelDefaults().debug.grad_check 开启时 armGradient 自检（测试 test_gradcheck 以中心差分 < 1e-5 对照）。

参数含义默认
model模型对象—
q1×N 关节角—
target[x,y,θ]—
tol_grad梯度范数阈值cfg.localmin_tol_grad (1e-3)

7.3 L2 方法层9 种求解器 + auto 调度 + 无梯度精修

① LGM 连通图

▶

② 候选集

▶

③ 逐段求解

7.4 L3 数学层运动学正解/雅可比、障碍距离与梯度
