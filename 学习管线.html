1为什么学（动机与范式）

问题：前面讲的 RRT* / graph 这类“离线全局最优规划”能解得很稳，但一次要秒级。真实电控/视觉融合需要毫秒级响应，两种需求对不上。

核心动机蒸馏

学习的目的不是“发明新算法”，而是把离线全局最优规划的实际工作找一条“没遇到过的新布局”时压成一次前向推理——把“老师”（RRT*）的已知答案蒸馏成“学生”（网络）的直觉。

离线规划（老师/天花板）：RRT* 预算内最优 → 秒级、质量高、稳

2数据管线与示范生成原理

学习质量的下限由“老师”决定。因此示范生成不是随便跑几条可行解，而是预算内最优 + 轨迹短切。这是整个方法能“与 RRT* 拉得近”的根因。

generateDemonstrationsstats = generateDemonstrations(opts)数据

流程：任务族采样 → RRT* 渐近最优规划 → 轨迹优化（随机短切 + 滑动平滑）→ 碰撞校验 → 分片保存（断点续生成）→ manifest 汇总。

关键设计决策与原理

  • 预算内最优示范（“老师天花板 = 学生天花板”）：若示范只是“早停的可行解”，学生大概率也只能学到“平庸解”，策略与 RRT* 拉不开差距。于是示范改为预算内最优（RRT* 跑足预算 + optimizeTraj 短切），把“最好答案”当标签。经验：路径质量提升约 40%，最优性差距从 +86.4% 降到 +20.8%。
  • 多摸态分布（difficulty 1–3 混合）：覆盖“稀疏 → 多障碍密集”布局，让策略见过各种难度。
  • 维度无关的 schema demo-v1：traj=[T×D]，D 由采样器决定；3D 演进只换采样器与几何适配层。

数据格式（schema demo-v1）

每分片 demo_XXXX.mat 含 demos(1:n)，每条的字段：
  .q0        [1×D]     起始构型（D = 关节维度）
  .target    [1×K]     目标（2D: [x,y,θ]）
  .traj      [T×D]     关节轨迹（原始路径节点，含 q0 与终态）
  .cost      路径代价（C-space 加权长度，渐近最优对象）
  .obstacles struct('circles',...,'rects',...)
  .meta      struct(rrt_max_samples / smooth_window / plan_s / tree_nodes)
manifest.mat：schema_version / n_total / 生成参数 / 统计

任务采样（sampleTask2D）的几何自适应

障碍分布在可达域半径 R=N·L 的 [0.35R, 0.9R] 环带（避开中心与边缘不可达区）
起始构型须自由：min g ≥ rho0 + 0.12（贴障碍起点可扩展锥极窄，RRT 难生长）
目标可达：随机构型 FK 末端 ± target_sigma 扰动（目标点必须在障碍外）
为什么“目标对齐示范”有效、而“扰动变体”无效：（P0 验证）示范若扰动目标生成，会造成分布漂移；目标必须与真实任务对齐（±0m 扰动），而 q0/障碍可做小幅扰动。

3三条学习路线总览

路线模型输入 → 输出损失 / 目标定位
BC条件 MLP（3 层, hidden 256）[grid|q0|target] → 增量轨迹 ΔMSE(重建, 真值)管线验证 / 基线
CVAEenc→μ,logσ + dec(x,z)→traj[grid|q0|target] → z 采样 → ΔELBO = MSE_recon + β·KL主策略（多模态）
RL线性策略 π_θ(s)=θ·s'状态特征 s → 关节增量ES 最大化 −(误差)经验加速 / 任务内现训
三者的共同特征：①都用增量表示（输出 Δ，而非绝对角），起点由 q0 锚定；②都用同一套特征（栅格 + q0 + target）与归一化；③部署端都接同一套“终点无梯度精修”。

4公共特征编码与数据预处理

训练与推理要严格一致，否则标签错位。特征由三块拼成：

x = [ reshape(occupancy_grid.', 1, []),        % 64×64 栅格，行主序 flatten
      (q0 − q_mean) ./ q_std,                    % 起始构型·归一化
      (target − t_mean) ./ t_std ]               % 目标 [x,y,θ]·归一化

栅格化（rasterize_obs / rasterize2D）

GRID=64，EXTENT=(-5,9,-7,7)（6 臂×1.04393m：可达域半径 6.26，宽 14 含余量；≈0.22m/格）
圆占据：‖(gx−cx, gy−cy)‖ ≤ r ⇒ 1
矩形占据：旋转坐标下 |lx|≤w/2 且 |ly|≤h/2 ⇒ 1

增量表示（核心）

Δ[k]   = traj[k] − traj[k−1]，首行 = traj[0] − q0 = 0（起点不动）
traj(q) = q0 + cumsum(Δ, 1)                   % 起点锚定在 q0
归一化：Δ_n = (Δ − y_mean) ./ y_std；反归一化：Δ = reshape(y,T,N)·y_std + y_mean
为什么用增量而非绝对角：轨迹的“走向”与“起点”解耦——网络只需要学“怎么动”，起点由 q0 锚定。这样即使 q0 变化，输出仍能无缝拼接，避免网络“从别的地方开始”。

5BC 行为克隆管线验证 / 基线

train_policy.py · bcPolicyFromFilemodel = BCMLP(d_in, d_out) → out = bcPolicyFromFile(mat_file, model, q0, target)BC

核心直觉：把“老师”的示范轨迹当正确答案，做一个条件回归：给 x=[grid|q0|target]，让网络预测 Δ。这是模仿学习最朴素的“照抄”形式。

数学逻辑

min_θ  E_{(x,Δ)~D}[ ‖ f_θ(x) − Δ ‖² ]                    % MSE 监督回归
f_θ：3 层 MLP（hidden 256，ReLU）→ [T_OUT×N] 展开
T_OUT=64（变长轨迹先重采样到 64 点）；输出经 y_std·y + y_mean 反归一 → Δ → traj

实现细节

  • 数据：load_demos 读 demo_*.mat，resample_traj 重采样到 64 点。
  • 归一化：q0/target 各向 mean/std；Δ 增量归一化。
  • 训练：Adam lr=1e-3，9:1 划分防泄漏；--epochs 30。
局限（为什么只是基线）：BC 是单值回归——遇到“绕左/绕右”这种多模态分叉，它只会输出一个“平均路径”，可能穿过障碍。多模态需要 CVAE / Diffusion。

6CVAE 多模态轨迹生成（主策略）理论核心

train_cvae.pyELBO = MSE_recon + β·KL(N(μ,σ²) || N(0,1))CVAE

核心直觉：BC 只能“平均”，遇到“绕左边还是绕右边”会折中。CVAE 引入一个潜变量 z：不同的 z 对应不同的“绕行方式”，于是能表达多模态；推理时从先验 z~N(0,1) 采多个 z，得到多条可选的绕行路径。

数学逻辑（条件变分自编码器）

编码器 q_φ(z | x, y) = N(μ(x,y), σ²(x,y))，μ,logσ 由 enc(x,y) 输出
解码器 p_θ(y | z, x) = dec(x, z)  →  Δ；y = Δ

重参数化：z = μ + σ ⊙ ε，ε ~ N(0, I)（梯度可回传）
训练损失（ELBO 上界）：
  L = E_{q_φ}[ ‖ p_θ(y|z,x) − y ‖² ] + β · KL( q_φ(z|x,y) || N(0,1) )
KL(q_φ ‖ N(0,1)) = −½ Σ_j[ 1 + log σ_j² − μ_j² − σ_j² ]    % 解析
β = 0.5（首版保守，保重建质量）

网络结构

encoder: Linear(d_in+d_traj,256) → ReLU → Linear(256,256) → ReLU → Linear(256, d_z*2)   % μ, logσ
decoder: Linear(d_in+d_z,256) → ReLU → Linear(256,256) → ReLU → Linear(256, d_traj)
d_z=16（潜空间），hidden=256，d_traj=T_OUT*N=64*6=384

参数

参数值作用
GRID / EXTENT64 / (-5,9,-7,7)栅格分辨率 / 工作空间
T_OUT64轨迹重采样点数
D_Z16潜空间维度
BETA0.5KL 权重（平衡重建与多模态）
--initNone微调：沿用 init 模型的归一化量，保持权重-输入一致

7潜空间优化推理（KL 塌缩的解法）部署核心

cvaePolicyFromFileout = cvaePolicyFromFile(mat_file, model, q0, target, n_cand, z_iters)推理

问题（KL 塌缩）：训练时编码器输入了 y（真实轨迹），后验 q_φ(z|x,y) 很“尖”；可部署时只有 x，z 只能从先验 N(0,I) 采样。两者分布不匹配，直接采样 z 往往生成差轨迹。

数学逻辑（把 z 当成优化变量）

定义终态误差 E(z) = ‖ p(traj(z)) − X_t ‖ + 0.1 · |wrap(θ(traj(z)) − θ_t)|
其中 traj(z) = q0 + cumsum( decode(x, z) )

数值梯度（中心差分，dz=16 维）：
  ∂E/∂z_j ≈ [ E(z + h·e_j) − E(z − h·e_j) ] / (2h)，h=0.05

优化：z ← z − lr·∇_z E，lr=0.15，迭代 z_iters=25 次
多起点：对 n_cand=4 个 z ~ N(0,I) 各自优化，取 E 最小者（多模态绕行）

实现步骤

  • 特征 x（栅格 + q0 + target 归一化）→ 对每个候选 z 做潜空间梯度下降。
  • 解码 → Δ → traj=q0+cumsum(Δ) → 限位投影 → 算终态误差。
  • 取误差最小的 z 对应轨迹；再叠加一次多起点无梯度精修（从轨迹末端或 1/3 处出发）。
为什么这招能救：潜空间优化把“生成”从“随机采样”变成“朝着末端误差最小方向找 z”，绕开训练/部署先验不匹配——是部署端把 CVAE 真正“用起来”的关键。

8RL：OpenAI-ES 进化策略黑箱参数搜索

trainRLPolicy.m · rlRollout · method_rltheta ← theta + lr·(ε'·R̂)/(n_pop·σ)RL

核心直觉：不建模、不求导，直接在策略参数空间做随机扰动 + 择优：一堆“候选参数”各自试跑，表现好的方向就是该更新的方向。这是进化策略，天然适合“奖励不可导”的避障问题。

数学逻辑（OpenAI-ES 参数扰动 + residual 集成）

状态特征 s = [ e_pos归一化(2), e_ang/π, min_g归一化(1), q归一化(N) ]，D=2+1+1+N
策略 π_θ(s) = θ·s'  ∈ R^N（线性）
动作 dq = −0.05·∇V' + λ·π_θ(s)      % residual：动量梯度 + 学习项

ES 梯度估计（似然比 / 重参数化扰动）：
  采样扰动 ε_p ~ N(0, σ²I)；奖励 R_p = −(dist_end + 0.1·ang)（累加 tasks_per_gen 个任务）
  归形 R̂ = (R − mean) / max(std, ε)
  ∇_θ J ≈ (1/(n_pop·σ)) Σ_p R̂_p · ε_p        % 把“哪个扰动好”的梯度计入 θ
  θ ← θ + lr·reshape(ε'·R̂, size(θ))/(n_pop·σ)，lr=0.5，σ=0.2

为什么 θ=0 起步不劣于纯梯度

当 θ=0 时 π_θ=0，动作退化为纯动量梯度 dq=−0.05·∇V。所以 residual 集成的收益是“只会更好，不会更差”——这是设计上的安全底线。

两种运行方式

  • 离线任务族训练（trainRLPolicy）：每代 4 个任务，进化 500+ 代，可续训（Ctrl+C 断点保存），早停成功率达 90%。产出 RLPolicy.mat（θ + 元数据）。
  • 任务内现训（method_rl）：默认若有 RLPolicy.mat 且 N 匹配则自动加载，否则回退任务内现训。
优点奖励可非平滑；θ 可导出复用；不劣于纯梯度基线。
局限线性策略表达受限；需大量采样评估；只在目标附近有效。

9模型导出与 MATLAB 手写 forward

训练端用 Python（PyTorch），部署端是 MATLAB——两套语言不共享运行时。因此把权重 + 归一化参数导成 .mat，再在 MATLAB 里手写同构的 forward。

导出 .mat（train_cvae.py）

mat = { q_mean, q_std, t_mean, t_std,        % 归一化统计量
        y_mean, y_std,                          % 增量 Δ 的（部署 traj=q0+cumsum(Δ)）
        T, N, grid, extent, dz, dtype, delta }
        + decoder 权重：dec_0_weight, dec_0_bias, dec_2_*, dec_4_*  % state_dict 点→下划线

MATLAB 手写 forward（cvaePolicyFromFile）

x = [reshape(img.',1,[]), (q0−q_mean)/q_std, (target−t_mean)/t_std];
h = x * dec_0_weight' + dec_0_bias;  h = max(h,0);      % ReLU
h = h * dec_2_weight' + dec_2_bias;  h = max(h,0);
y = h * dec_4_weight' + dec_4_bias;
Δ = reshape(y,T,N) .* y_std + y_mean;  traj = q0 + cumsum(Δ,1);  traj = clip( q_min, q_max );
一致性的两个坑：①行主序——用 reshape(img.',1,[]) 而非 img(:)（后者是列主序），必须与 train_cvae.py 的 .flatten() 一致；②维度校验——策略 N 与模型 N 不匹配就 error（需重新训练对应 N 的策略）。

10部署闭环（cvaePolicyDeploy）

cvaePolicyDeployout = cvaePolicyDeploy(mat_file, model, q0, target)部署

核心思想：学习策略是“快速但不可靠”，所以要加一层安全保护：先试直出，不行就回退到传统规划器。

流程

1. CVAE 潜空间优化生成粗轨迹（毫秒~数百 ms）
2. 安全校验 isFreeTraj：全程 obsDistAll ≥ rho0？
   误差 err_end = ‖p−X_t‖ + 0.1·|wrap(θ−θ_t)|
   ▼
3. 若穿障 或 err_end > 0.08（直出质量差）⇒ 回退 method_auto（max_samples=2500）
   out.via ← 'cvae' | 实际方法名
4. 终态严格收敛精修：refineRandomGreedy(layers=3, steps=120, goal_eps=0.008)，循环 ≤3 次
   ▼
out = { traj, q_final, via, dist_end, ang_err }
为什么直出阈值设 0.08：防止“粗直出”被误判为已收敛——留出“它其实没到”的余地，触发回退，保证可靠性兜底。整个部署闭环的哲学就是：“学习做快决策，传统规划兜底。”

11评估与验收准则

evaluatePolicyres = evaluatePolicy(policy, opts)评估

核心直觉：任何策略函数统一映射成一组指标；用独立采样的测试集（不泄漏到示范训练集）衡量。

评估指标

success_rate   终态达标比例：‖p−X_t‖ < goal_pos(0.1) 且 |θ−θ_t| < goal_ang(0.2)
collision_rate 全程侵入障碍比例（应为 0）
mean_end_pos / mean_end_ang
mean_gap       最优性差距 = mean((c_policy − c_baseline) / c_baseline)
               c = Σ‖Δq‖（C-space 路径长度）；baseline 用 RRT*（参考侧也做 optimizeTraj 短切，近全局参考）
mean_gen_s     策略生成平均耗时（ms）

res = evaluatePolicy('rrtstar');                       % 基线自评
res = evaluatePolicy(@(m,q0,t) cvaePolicyDeploy(...)); % 自定义策略
验收缺口（已知）：若策略只给 q_final（无轨迹），无法算路径代价，会跳过 mean_gap（避免误报 −100%）。

12模型栈、演进方向与文件清单

模型栈（含规划中的扩展点）

模型架构输入 → 输出作用
主策略 CVAEhidden 512 / d_z=32（新臂长）64×64 栅格 + q0[6] + tgt[3] → 64 步增量轨迹直出候选轨迹（多模态）
可解性分类器（P1）CNN(64×64→128) + MLP栅格 + q0 + tgt → P(可解)毫秒预检，不可解直接拒绝
代价引导网络（P2 可选）MLP 256栅格 + q0 + tgt → V̂(最优代价)RRT* 有向采启发式（回退加速）

关键架构决策

  • CVAE增量表示（traj=q0+cumsum(Δ)）——已验证（旧模型必须）。
  • 潜空间优化推理（多候选 z + 数值梯度）——解决 KL 塌缩下分布不匹配。
  • 可解性分类器输出软概率 → 部署时同时作“直出置信度”（P(可解)<0.5 时优先回退而非硬拒绝）。
  • 失败域对齐示范：对“部署闭环失败”的任务，目标不扰动地重解示范（P0 核心结论）。
