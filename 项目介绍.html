0项目全景

用一句话、一条链路、一块技术栈，让第一次接触的人 30 秒建立整体认知。

一句话：这是一个“视觉任务 → 运动学求解 + 仿真 → 电机指令导出”的中间模块。它不负责视觉感知，也不做实时伺服，只做三件事——任务展开、运动规划、离线轨迹导出；并把“离线全局最优规划”进一步蒸馏成毫秒级学习策略。

四个入口/常驻进程都被数据源驱动，在“求解语义”上汇入同一个共享内核，再各自产出下游负载。完整情景与接口格式见 runtime.html。

2.1 共享求解内核

  ├─ method_auto → momentum / RRT* / graph / PRM / SA / rl　·　另: multilayer（LGM，独立方法）

3求解策略与数学

覆盖梯度局部精修 → 采样全局 → 图引导 → 工作空间连通 → 学习加速五种范式，共享单一价值函数。完整数学推导、公式、参数表见 strategies.html。

3.1 五种范式

范式方法保证速度精度
梯度局部精修momentum局部收敛毫秒高（1e-4/1e-3）
采样全局rrt/rrtstar/prm/sa概率完备 / 渐近最优秒粗达 + 精修
图引导graph启发式（走廊可行）中粗达 + 精修
工作空间连通multilayer启发式（走廊连通，臂无关）中不碰障+在空间内 → 精修<0.03
学习加速rl/cvae经验毫秒~数百 ms≤0.01 + 精修
调度auto随层随场景对应实际用到的层

3.2 统一价值函数（全部方法共享）

V(q) = w_pos·‖p − X_t‖² + w_ang·wrap(θ − θ_t)²
     + w_obs·Σ[ log(r_bar) − log(g_eff) ]（屏障；g_eff = max(d−d_safe, g_min)）
     + w_var·Σ(q−μ)²/σ² + w_acc·‖v−v_prev‖²

3.3 auto 调度链与局部最优

momentum → RRT*(预算1) → RRT*(×2) → graph → PRM → SA → 取误差最小者
局部最优判定：‖∇V‖ < tol 且 末端未达 ⇒ 升级到采样层

4学习策略与部署

把“离线全局最优规划”蒸馏为毫秒级策略直出。完整理论、损失、导出格式、部署闭环见 learning.html。

4.1 三条学习路线

路线模型损失/目标定位
BC条件 MLPMSE 监督回归管线验证/基线
CVAEenc→μ,logσ + dec(x,z)ELBO = MSE + β·KL主策略（多模态）
RL线性 π_θ(s)=θ·s'ES 最大化 −误差经验加速 / 现训

4.2 关键理论

  • 增量表示：traj = q0 + cumsum(Δ)，起点锚定，网络只学“怎么动”。
  • 潜空间优化推理：部署时把 z 当优化变量，用中心差分数值梯度逼近末端误差最小——解决 KL 塌缩下训练/部署先验不匹配。
  • 预算内最优示范（老师天花板 = 学生天花板）：示范用“预算内最优 RRT* + 短切”，而非早停可行解——这是与 RRT* 拉不开差距的根因。

4.3 部署闭环

直出(CVAE) → 安全校验 isFreeTraj → 穿障/误差>0.08 回退 method_auto → 终点精修 ≤0.008

6.3 数值防御（为何“稳定”）

  • g_min 防除零、barrier_C 幅值截断、wrapAngle 角度连续化。
  • 障碍几何退化分支（点/平行段）显式处理防除零（segSegDistGrad）。
  • 已修的“隐性 bug”：末端朝向角方向（全零构型 θ=π→0）；RRT 边碰撞只查端点→沿边插值多采样防穿段漏检。
  • 确定性：method_rl 用 rng(1)，训练 --seed 0 + cudnn.deterministic。
诚实声明：以上是单元/模块级验证。目前没有系统级端到端验收框架（视觉→任务→执行→回传的整链指标）——这是 P1 缺口（见 §7）。

7已知局限与边界 补充

主动讲清“还没通在哪”，是专业与可信的体现。下面合并方法级局限与系统级验收缺口。

7.1 方法级局限

方法何时会失败 / 局限
momentum只到局部最优；被障碍势阱困住出不来；对屏障非凸性敏感
rrt/rrtstar慢；只能“粗达+精修”；预算不足会在窄通道失败（靠 auto 升档 ×2）
graph走廊只约束末端位置（不约束姿态），最后一段才处理角度
multilayerLGM 建图需场景（骨架依赖 Image Processing Toolbox）；连通图不含可行性，候选段可能失败 → fallbackSolve
sa慢；只能“接近 + 精修”；冷却参数敏感
rl线性策略表达受限；需大量采样；只在目标附近有效
cvae需离线示范；域外/未训练布局会穿障，靠安全层回退兜底
全域约 8.7% 任务疑似不可解（目标被障碍吞没等）——需可解性分类器（P1）

7.2 系统级验收缺口（P0，阻真实交付）

优先级缺口现状影响
P0手眼标定 T_base_cameraprojectTo2D 直接把相机系当基座系（“标定前仿真模式”）相机位姿无法换算到基座系——真实夹取无法定位
P0真实电机参数限位默认 ±3rad、零位/方向/速度上限为假设规划解可能超出真实行程/方向反
P0末端几何（夹爪+相机）运动学末端 = 最后关节夹持点/相机光心与末端不重合，有固定偏差
P0电控执行反馈通道当前离线下发，dSPACE 执行结果无回传状态机断在 EXECUTING，软件不知执行成功/失败
P1端到端联调 / 系统级验收框架 / 夹取闭环当前为 mock 端到端缺整链指标与真实反馈

读法：软件核心（规划/任务/仿真/策略）完成度约 90%，但系统级集成尚有 4 个 P0 缺口——全部依赖真实机械臂/相机/电控现场数据，软件侧可先行准备好（云重训 + mock 验收框架）。

8与已有方法/文献对比 补充

回答“为什么不直接用一个现成算法”——即每个设计选择背后的“对比与权衡”。

设计选择备选为何选当前
RRT* 而非 RRTRRT（更快、简单）需要渐近最优的路径质量；RRT 会绕路。RRT* 用 choose-parent + rewire + 半径收缩。
CVAE 而非 BCBC（单值回归）避障有多模态（绕左/绕右）；BC 只输出“平均路径”，可能穿障；CVAE 用潜变量 z 表达分叉。
residual RL纯 RL / 纯梯度动作 = 梯度 + λ·π_θ(s)；θ=0 时退化为纯梯度，保证“不劣于基线”。
潜空间优化推理直接采 z采样 z 受 KL 塌缩影响（部署先验≠训练后验）；把 z 当优化变量逼近末端误差最小。
文件桥（outbox⇄inbox）IPC / 共享内存进程解耦、可独立重启、确定性、易日志/回放；代价是轮询延迟。
离线求解 + 确定性回放在线 IK 进实时循环实时循环只做插值，避免迭代求解的不确定性与耗时。
单一共享价值函数各方法各写一套代价避免“多套代价互相腐败”，可机器精度校验，一处一事实。
文献锚点：RRT* 沿 Karaman & Frazzoli (2011)；半径 r = γ·(log n/n)^(1/N)；VAE/CVAE 重参数化训练；OpenAI-ES 参数扰动策略梯度。
