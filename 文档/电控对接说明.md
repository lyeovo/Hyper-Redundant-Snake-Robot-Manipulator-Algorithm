# 电控对接说明（dSPACE 集成）

> 面向 dSPACE 电控工程师。说明 runLArmIK 模块如何向电控输出电机指令，以及 dSPACE 端如何加载、插值、执行与安全监控。
> 对应主设计文档：`文档/实现方案.md`（§1.2 dSPACE 执行模式、D14）。

## 1. 系统链路

```
相机/视觉模块 (SpaceSnakeVisionUI)          runLArmIK 模块（MATLAB）             dSPACE 电控（硬实时）
  UI 任务面板 ──TaskCommand JSON──▶ task_executor ──simulateMotion──▶ motorCmd ──文件──▶ 轨迹插值 → 关节伺服 → 电机
  (data/outbox)  ◀──TaskStatus── (data/inbox)                       (motorCmd.mat/CSV)  安全监控/夹爪状态机
```

分工：
- **runLArmIK 模块（MATLAB，非实时）**：解析任务 → 求解轨迹 → 输出完整电机指令文件。**不参与实时控制。**
- **dSPACE（硬实时，典型 1 ms 周期）**：加载指令文件 → 按时间节拍插值 → 关节伺服 → 安全监控 → 夹爪状态机。

**核心原则：IK 求解（梯度下降/RRT/PRM 等迭代算法）绝不进入 dSPACE 实时循环**——其迭代次数与耗时不确定，不满足硬实时确定性。本模块离线求完整轨迹，dSPACE 只做确定性插值执行。

## 2. 交接文件：motorCmd

每次任务（或任务中的每一运动段）求解完成后，模块输出一个 motorCmd 文件。推荐格式 `.mat`（MATLAB 原生，精确）；需要跨平台/文本可读时导出 CSV。

### 2.1 字段表

| 字段 | 维度 | 类型 | 说明 |
|---|---|---|---|
| q_seq | K×N | double | 关节角快照序列（每 m 步一行）。N = 臂关节数 |
| t_seq | 1×K | double | 对应时间戳（**相对时间，执行起点 = 0**，单位 s） |
| gripper_seq | 1×K | int | 夹爪指令序列（见 §4），与 q_seq 对齐 |
| dq_max | 1×1 | double | 单步最大关节增量（rad/快照间隔），用于限速校验 |
| vel_ok | 1×1 | logical | 差分校验通过：相邻快照 `|Δq| ≤ m·dq_max` |
| safety_ok | 1×1 | logical | 轨迹全程无碰撞（所有段到所有障碍 `d ≥ rho0`） |
| success | 1×1 | logical | 求解成功（末端收敛到目标容差内） |
| error_code | 1×1 | int | 错误码（见 §6），success=true 时为 0 |
| q_final | 1×N | double | 末端收敛关节角 |
| meta | struct | - | command_id、task_type、method、N、L_seg、时间戳等溯源信息 |

### 2.2 .mat 示例（MATLAB 侧生成）

```matlab
info = simulateMotion(model, 'momentum', q0, [2.5, 1.0, 0.5], 'Snapshot', 10);
exportMotorCmd(info, 'motorCmd.mat');            % .mat（save -struct，推荐）
exportMotorCmd(info, 'motorCmd.csv', 'GripperSeq', gs);   % CSV + 夹爪序列
% 任务级：taskExecute 返回的 info.motor_cmd 直接导出（含 gripper_seq 自动对齐）
```

`exportMotorCmd.m` 已内置：兼容 `simulateMotion` info 与 `taskExecute.motor_cmd` 两种输入，输出字段与 §2.1 表完全一致。

### 2.3 CSV 示例（每行一个快照）

```csv
t, q1, q2, q3, q4, gripper
0.000, 0.0000, 0.0000, 0.0000, 0.0000, 1
0.167, 0.0234, -0.0451, 0.0112, -0.0089, 1
0.333, 0.0512, -0.0987, 0.0234, -0.0198, 1
...
3.000, 0.4120, -0.8231, 0.2345, -0.1987, 2
```

## 3. 坐标系、单位与时间约定

| 项 | 约定 |
|---|---|
| 工作平面 | **水平面**（robot_base 的 X-Y 平面，Z 垂直向上）。机械臂关节旋转与运动只发生在平面内 |
| 单位 | 长度 m，角度 rad |
| 关节角 q | 平面内旋转角（rad），范围由 `q_min/q_max` 约束（默认 ±π） |
| 时间 | `t_seq` 为**相对时间**（执行起点 = 0），由 dSPACE 按自身系统时钟触发，不做跨平台时钟同步 |
| 目标位姿 | `[x, y, θ]`（θ = 绕垂直轴 Z 的 yaw） |
| 视觉→基座 | 视觉输出相机系 3D 位姿；`T_base_camera` 手眼标定完成前 `pose_base=null`，**只允许仿真**（`allow_real_execute=false`），不发送真实电机指令 |

## 4. 夹爪指令（gripper_seq）

夹爪为**简单状态机**，由 dSPACE 电控实现。模块只在 `gripper_seq` 中标记状态切换时刻：

| 值 | 含义 |
|---|---|
| 0 | 保持当前状态 |
| 1 | 张开（open） |
| 2 | 闭合（close） |

约定：`gripper_seq` 与 `q_seq` 逐行对齐；某行值为 1/2 表示"到达该快照时刻执行张开/闭合"，为 0 表示该时刻臂运动但夹爪保持。电控端对夹爪状态机拥有最终解释权（可自行定义保持时间、夹持力等）。

## 5. 安全机制（双层，互不依赖）

| 层 | 负责方 | 内容 |
|---|---|---|
| 轨迹级 | runLArmIK 模块 | `safety_ok`：全程 `d ≥ rho0`（d = 机械臂所有段到所有障碍边缘的最小距离）；`vel_ok`：快照差分满足电机速率上限 |
| 硬件级 | dSPACE 电控 | 关节位置限位、速度限位、急停（`emergency_stop`）、夹爪状态机。**最终安全兜底，不依赖 MATLAB 侧正确性** |

建议 dSPACE 侧：
1. 加载 motorCmd 时先校验 `safety_ok && vel_ok && success`，不满足则拒绝执行并上报；
2. 执行中独立监控各关节角是否越限（即使轨迹文件有误也能兜底）；
3. 急停指令（来自视觉 UI 的 `emergency_stop` TaskCommand）可随时打断插值器，优先于轨迹执行。

## 6. 错误码（error_code）

| 码 | 含义 | 电控建议动作 |
|---|---|---|
| 0 | 成功 | 执行轨迹 |
| 1 | 任务不可达（目标超出可达域，预留） | 拒绝执行，上报视觉 UI |
| 2 | 求解未收敛（末端误差超 tol） | 可尝试重规划（换方法），或拒绝 |
| 3 | 无可行路径（全局规划失败，有障碍） | 拒绝执行 |
| 4 | 轨迹含碰撞（safety_ok=false，预留） | 拒绝执行 |
| 5 | 初始位姿反解失败（q0 为末端位姿时） | 请求电控回读当前实际关节角 |
| 6 | 任务被取消 / 急停 / 拒绝 | 停止执行 |
| 7 | 卡住 / 任务展开异常 | 重规划或拒绝 |
| 8 | 段求解异常（单段规划抛异常） | 拒绝执行，上报 |
| 9 | 终态碰撞（轨迹级 safety 校验失败） | 拒绝执行 |
| 10 | 目标被障碍吞没（段目标距障碍 < rho0） | 拒绝执行，上报 |

`success=false` 时电控**不应**执行该文件，应回传视觉 UI `TaskStatus = FAILED`（附 error_code）。

## 7. dSPACE 端插值建议

- `q_seq` 是**慢速参考轨迹**（相邻点间隔 = m 步 × 每步耗时），dSPACE 在其间插值：
  - 推荐**三次样条插值 + 限速**（模块可选提供 `info.q_smooth` 已做样条/限速后处理）；
  - 简单场景可用线性插值 + 速率钳制；
- 插值输出作为关节伺服位置环参考，电控自带速度/力矩环；
- 插值器按 `t_seq`（相对时间）推进，与 dSPACE 系统时钟对齐。

## 8. 联调步骤（验收）

1. **离线检查**：在 MATLAB 跑通 `simulateMotion`，检查 `success/vel_ok/safety_ok` 全 true，导出 motorCmd.mat；
2. **ControlDesk 加载**：在 dSPACE 侧加载 motorCmd.mat（或 CSV），检查字段解析正确、`t_seq` 递增；
3. **开环播放**：无电机（或仿真机）播放轨迹，观察插值输出连续、无突变；
4. **闭环伺服**：接入关节伺服，验证跟踪误差在允许范围；
5. **安全注入**：人为破坏 motorCmd（safety_ok=false / 越限）验证 dSPACE 拒绝执行与急停路径；
6. **全链路**：视觉 UI 发布 `pick_and_place` 任务 → task_executor 展开 → 逐段求解 → 导出 motorCmd → dSPACE 执行 → TaskStatus 回写 UI 显示 COMPLETED。

## 9. 与视觉 UI 的状态闭环（供电控了解上下文）

任务执行状态机由 MATLAB 侧 `task_executor` 维护并回写视觉 UI（`data/inbox/*_status.json`）：

```
RECEIVED → ACCEPTED → PLANNING → EXECUTING(progress + joint_positions 快照) → COMPLETED / FAILED / CANCELED / ESTOP_TRIGGERED
```

电控侧需要配合的只有一个点：**执行阶段如果发生硬件级异常（越限/急停），通过约定的状态文件或回调告知 task_executor**，使其回写 `FAILED`/`ESTOP_TRIGGERED` 给 UI。具体通信机制（文件/ControlDesk 变量/CAN）待联调时确定，第一版用文件桥（inbox）即可。
