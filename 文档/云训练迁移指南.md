# 云服务器训练迁移指南

> 背景：本地训练受 CPU 限制（6000 条 80 epoch ≈ 2 分钟纯 CPU 已够用，但**大规模训练**（hidden 512+、数万条示范、多轮实验）建议上云 GPU。
> 本文档：数据打包 → 云环境 → 训练命令 → 模型回传的完整流程。

---

## 1. 训练脚本现状（已云就绪）

`rl_pipeline/train_cvae.py` 已支持：

| 特性 | 状态 |
|---|---|
| **设备自动选择** | ✅ `cuda → mps → cpu` 自动回退（`DEVICE` 全局），模型/张量 `.to(DEVICE)`，导出前转 CPU |
| **多目录数据** | ✅ `--data dir1 dir2 ...`（合并加载 + 全局乱序） |
| **微调续训** | ✅ `--init policy_xxx.mat`（加载权重 + 沿用原归一化统计量，权重-输入一致） |
| **完整可复现** | ✅ `--seed` 同时设 torch/numpy/random 三源 + cudnn deterministic |
| **参数化** | ✅ `--epochs/--lr/--hidden/--dz/--out` |
| **数据驱动** | ✅ 关节数 N 从数据读取，不硬编码 |

## 2. 数据打包

```bash
# 本地（Windows）——示范数据目录打包
tar -czf demos_full.tar.gz demonstrations_c1_* demonstrations_c3_* demonstrations_var*
# 或最小集（仅训练所需）：
tar -czf demos_v2.tar.gz demonstrations_var* demonstrations_c1_1 demonstrations_c3_1
```

**注意**：
- 示范文件格式 `.mat`（scipy.io 可读），每个含 `q0 [1×N] / target [1×3] / traj [T×N] / obs 结构`；
- `train_cvae.py` 只读 `q0/target/traj` 字段（`load_demos` 内 `d["q0"]/d["target"]/d["traj"]`），obs 不读——**障碍栅格由 `rasterize_obs` 从 obs 重建**（需确认 load_demos 是否含 obs 字段）。

## 3. 云环境安装

```bash
python -m venv venv && source venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cu121   # GPU 版（按需选 cu 版本）
pip install numpy scipy
```

- 无 GPU 环境也能跑（自动回退 CPU）；
- 训练数据放任意路径，`--data` 传目录即可。

## 4. 训练命令模板

```bash
# 全量重训（大容量 hidden 512，建议 GPU）
python rl_pipeline/train_cvae.py \
  --data demonstrations_c1_1 ... demonstrations_c1_6 \
         demonstrations_c3_1 ... demonstrations_c3_6 \
         demonstrations_var1 demonstrations_var2 demonstrations_var3 demonstrations_var4 \
  --init rl_pipeline/policy_cvae_c1_ft.mat \
  --out rl_pipeline/policy_cvae_v2 \
  --epochs 60 --lr 3e-4 --hidden 512 --seed 1

# 纯微调（小步长防遗忘）
python rl_pipeline/train_cvae.py \
  --data demonstrations_var1 demonstrations_var2 demonstrations_var3 demonstrations_var4 \
  --init rl_pipeline/policy_cvae_c1_ft.mat \
  --out rl_pipeline/policy_cvae_v2_ft \
  --epochs 30 --lr 1e-4 --hidden 512 --seed 1
```

**参数建议**：
- 直出率提升实验：`--hidden 512`（大容量）+ 全量数据；
- 失败域补强（P0 主线）：`--init` 从 C1_ft 微调 + 变体数据，`--lr 1e-4~3e-4`、`--epochs 30-60`；
- 纯新训练：`--epochs 80`、`--lr 1e-3`。

## 5. 模型回传与部署

```bash
# 云上下载 policy_cvae_v2.mat → 本地 rl_pipeline/
scp user@host:rl_pipeline/policy_cvae_v2.mat rl_pipeline/
```

本地部署验证（MATLAB）：

```matlab
addpath('ArmSimulator2D');
verifyPolicy(struct('policy_file','rl_pipeline/policy_cvae_v2.mat','n_test',40,'seed',11));
```

或 GUI：方法下拉选 `cvae 策略（L2 模型）`，策略文件路径填 `rl_pipeline/policy_cvae_v2.mat`。

## 6. 注意事项

1. **归一化统计量**：`--init` 微调沿用旧模型统计量（保持权重-输入一致）；全新训练用新数据统计量——**两种模式导出的 .mat 部署端通用**（`cvaePolicyFromFile` 读 q_mean/q_std 等字段）；
2. **hidden 维度变化**：`--hidden 512` 与 `--init` 的旧权重维度不一致会报 `size mismatch`——**大容量重训不要配 `--init`（旧权重是 256）**，或先全量重训再微调；
3. **数据量**：6000+1002+440 ≈ 7500 条 × 64 帧 × 6 维——GPU 训练 <10 分钟/80 epoch，CPU 20-40 分钟；
4. **多实例训练**：不同 `--seed` 并行跑多份（数据只读），取 val 最优；
5. **磁盘**：示范目录 ~10-20GB（.mat 压缩后），打包前 `tar` 压缩可减 60%+。
